# Interactive Digit Classifier

## About

An interactive program that uses a neural network to classify hand-drawn digits.

This project features two implementations of the same model: one built from scratch using **NumPy** and another using **PyTorch**. The goal is to understand the fundamentals of neural networks by implementing the underlying mathematics and comparing it with a deep learning framework.

## Implementations

### NumPy
A neural network implemented from scratch to explore forward propagation, backpropagation, activation functions, and gradient descent.

[View NumPy implementation](numpy_digit_classifier/README.md)

### PyTorch
A recreation of the NumPy model using PyTorch to explore automatic differentiation and built-in optimization tools.

[View PyTorch implementation](pytorch_digit_classifier/README.md)
